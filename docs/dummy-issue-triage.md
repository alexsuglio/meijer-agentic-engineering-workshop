# Dummy issue-triage checklist

This is synthetic demo content for practicing GitHub issue triage. It is not a
production requirement and does not implement or change any workshop lab.

Related demo issue: [#3](https://github.com/alexsuglio/meijer-agentic-engineering-workshop/issues/3).

- [ ] Confirm the issue's scope and identify what is out of scope.
- [ ] Record synthetic reproduction steps, expected behavior, and actual behavior.
- [ ] Define observable acceptance criteria before making a change.
- [ ] Link the related draft pull request for review practice.
- [ ] Leave the demo issue open and its pull request unmerged.
